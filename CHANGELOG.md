# Changelog

## 0.1.0

- Added stdio LSP client connecting to `rustel lsp --stdio` for completion, hover documentation, and live lint diagnostics on `.strudel` and `.std` files.
- Added live score playback (`Ctrl+Enter` / `Cmd+Enter`), selection playback (`Ctrl+Shift+Enter` / `Cmd+Shift+Enter`), stop control (`Ctrl+.` / `Cmd+.`), and real-time mini-notation token highlighting via `rustel play --watch --ui-events`.
- Added Strudel syntax highlighting, language configuration, demo score, and zero-dependency tests.
